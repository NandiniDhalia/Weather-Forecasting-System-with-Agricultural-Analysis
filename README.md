# Weather Forecasting System with Agricultural Analysis

An interactive weather forecasting application developed using Python and Streamlit, with an integrated agricultural analysis module.

## Features

* Current Weather Information
* Weather Forecasting
* Weather Data Processing
* Interactive Weather Visualizations
* Agricultural Suitability Analysis
* Weather-based Agricultural Alerts

## Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SQLite
* OpenWeather API
* Agromonitoring API

## Project Structure

* `main.py` – Main application interface
* `weather_api.py` – Weather data retrieval
* `weather_processor.py` – Weather data processing
* `agricultural_analysis.py` – Agricultural analysis
* `database.py` – Database management
* `test_weather_api.py` – API testing

## Installation

1. Clone the repository.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Configure the required API credentials in a local `.env` file.
4. Run the application using `streamlit run main.py`.

## Execution

```bash
streamlit run main.py
```
